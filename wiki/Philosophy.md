# Philosophy

What PSX-DS is for, and what goes on each screen. These rules come from GBA DS, adapted for the PlayStation.

1. **A PS1 with a second screen.** PSX-DS plays as if the PlayStation had come with a second screen, neither of them a touchscreen. All the other rules follow from this one.
   - **Ask what the game would have done.** If this game had been made for a two-screen PS1, what would its developers have put on the second screen? Usually something it already has: the map, a status screen, an inventory.
   - **The game itself isn't changed.** The game you play runs as it would on a PS1. The second screen is filled from a hidden second copy of the game, which opens menus there without pausing your game, sending it input or changing its memory.
2. **Function over form.** Nothing on the second screen should make you look twice: no prompts, no cursor, no character you control, nothing split across the two screens.
3. **Keep it simple.** Prefer a screen the game already draws, opened on the hidden copy, over anything rebuilt from the game's memory.
4. **Only the game's own graphics.** PSX-DS doesn't draw new maps, panels or icons for a game.
5. **No in-game touch.** Touch is only for PSX-DS's own menus.
6. **Exceptions when they earn their place.** A game can break a rule when that's clearly better for playing it; each exception is written down with the game.

When a situation can't be detected reliably, PSX-DS shows less: the game's logo, or the last good picture.
